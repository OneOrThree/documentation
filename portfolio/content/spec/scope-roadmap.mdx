### 2.0.0에서 아직 미정 또는 후속 확인

정책 정본이 "남아 있는 구현 세부 기준"으로 명시한 것들이다. 위에서 확정한 재화·권한·건설 흐름을 다시 미정으로 돌리는 항목이 아니다.

- 주간 초기화 시간대와 데이터 지연 처리. **분당 적립의 하루 상한은 UTC 00:00으로 09-20 확정**됐으므로 이 항목의 미정 범위에서 제외
- 랭킹 집계 중 가입·탈퇴에 따른 분모 산정 시점
- 통신 실패·동시 구매·동시 건설의 중복 차감·보상 방지
- 달성한 주민이 개인 보상을 받지 않은 채 회차가 바뀔 때의 처리
- 낚시섬에서 다른 주민과 같은 위치를 눌렀을 때의 처리
- 모닥불 최대 15명 표시 방식(앞줄 일부 + `+N명`은 아직 제안)
- 휴식 중 앱 종료·백그라운드 처리
- 마지막 소속 섬에서 강퇴된 사용자의 처리
- 건설 목표 변경 시 이미 모은 몫을 새 목표로 이어서 셀지
- 일일 퀘스트 보상을 각자 몫에 넣을지

보고서 「개발 진행현황」은 같은 상태를 문장으로 적는다 — 1.0.0은 기본 앱 뼈대와 리그·친구·집중 세션(카운트업·카운트다운·뽀모도로)을 포함하고, 1.1.0은 그룹·누끼·재화를 추가해 심사에 제출했으며, 상점·캐릭터·집중 방 꾸미기·신고센터·AI 안전 필터링·누끼 캐릭터의 그룹·집중 세션·리그 공유는 1.1.0 출시 이후 순차 추가한다. 미완료 항목으로는 LLM 주간 회고, 수익화(광고·구독·상점), 누끼 서버 공유, Android 앱 개발·스토어 출시, 실사용 유지율·집중 개선 지표를 든다. Android는 구현 가능성 검토까지 마쳤고 개발이 남았다.

기획 스펙 대비 **자체 진척도**(2026-08-08 기준)는 6대 핵심 기능 평균 63%(380/600), 기획 타임라인 기준 65%(910/1,400)다. 분모가 기획 스펙이라 출시된 기능도 잔여 스펙이 있으면 100%가 아니다 — 주간 리그 95%·이탈 감지 85%가 상단, 실시간 그룹 집중 세션은 WebSocket 동기화와 누끼 공유가 남아 45%, LLM 주간 회고는 미구현이라 10%다.

### 재화 — 확정된 정책

재화 금액은 서버만 정한다. P1 클라 적립 전면 폐쇄(`POST /currency/earn`은 no-op), P2 서버 전용 6종 타입은 클라 경로에서 거절, P3 목표 달성 보상 = 스트릭 + 코인(스크린타임 목표는 스트릭 미배선), P4 낙관 가산 금지, P5 잔액 0과 모름의 의미 분리, P6 선지급 금지, P7 금액을 지어내는 폴백 금지 (`prd/currency/prd.md` §6). 상점 이벤트는 유보다 — 현재 앱에서 상점에 도달할 수 없고 구매 화면은 네비게이션에 등록돼 있지 않다 (§3.6).
