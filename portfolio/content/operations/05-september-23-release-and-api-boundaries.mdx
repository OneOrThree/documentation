## 2.0 iOS 배포

9월 23일 `app/app-dev`의 2.0.0 빌드 **4·5·6·7이 TestFlight에 업로드**됐다. 빌드 4는 당시 `main`을 fast-forward한 뒤 앱 아이콘을 IPA에서 확인했다. 빌드 5는 `ITSAppUsesNonExemptEncryption=false`를 실제 IPA에서 확인했고, 빌드 6은 타일 마을 미리보기를 연결한 뒤, 빌드 7은 흙길 밝기와 자갈 질감을 조정한 뒤 업로드했다. **업로드 성공은 Apple 처리 완료나 테스터 설치 확인과 다르다.** 빌드 4·5의 상세 검증은 `phone/docs/engineering/testflight/2026-09-23-ios-release.md`, 빌드 6·7은 `phone/logs/09-23.md` 기록이다.

2.0 앱의 푸시 수신과 딥링크는 이 빌드에 완료된 기능으로 적지 않는다. [GROMO-2090](https://romance.atlassian.net/browse/GROMO-2090)은 알림 목적지와 실패 시 이동, [GROMO-2091](https://romance.atlassian.net/browse/GROMO-2091)은 Firebase/APNs·기기 토큰·실기기 검증을 맡는다. 2090이 2091의 선행이다.

## 공개 API와 내부 전송의 분리

서버의 9월 23일 리팩토링은 API 응답의 **필드·값·null 계약을 유지하면서** 내부 전송 DTO가 외부 응답에 우연히 노출되는 경로를 도메인별로 끊는 작업이다. [#943](https://github.com/OneOrThree/phone/pull/943)은 공개 경로의 오류 HTTP 상태와 내부 장애 로그를 분리했다. [#944](https://github.com/OneOrThree/phone/pull/944)·[#948](https://github.com/OneOrThree/phone/pull/948)~[#955](https://github.com/OneOrThree/phone/pull/955)는 계정, 집중, 음악, 친구·차단, 외양, 주민 스냅샷, 섬 관리 등의 공개 DTO를 분리했다. 9월 23일 12시 기준 #943~#955는 머지됐고, #956과 #959~#965는 열려 있다. 머지 여부는 작성 이후 바뀔 수 있으므로 PR 링크의 상태를 우선한다.

기존 응답 JSON이 맞아도 문서가 틀릴 수 있었다. 공개 OpenAPI에서 서로 다른 도메인의 `Item`·`Member`·`Result`·`Deleted`라는 이름이 충돌해 상품·퀘스트·로그인 문서가 엉뚱한 필드를 가리켰다. 원인별 **12건의 잘못된 문서 필드/필수값**을 재현하고, [#956](https://github.com/OneOrThree/phone/pull/956)에서 스키마 이름을 분리했다. `phone/doc/ponytail-refactor-2026-09-23/final-audit.md`의 로컬 검증은 Business 테스트 1,853건과 정적 검사 통과이며, 이 기록만으로 PR 머지나 운영 배포를 뜻하지 않는다.

## 읽는 기준

서버 작업 범위는 **서버 전용**으로 정정됐다. 같은 날 앱 TestFlight 작업과 병행됐지만 공개 응답을 고치려고 앱을 함께 리팩토링한 것은 아니다. PR별 추가·삭제 합계 상한은 3,000줄, 계약 테스트를 먼저 두는 방식을 사용했다. 이 기준과 PR 상태는 `phone/logs/ponytail-server-refactor-2026-09-23.md`에 남아 있다.
