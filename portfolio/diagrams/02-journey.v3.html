사용자 목표혼자 또는 기존 섬에서 첫 집중을 시작할 준비를 한다.이번에 무엇을 얼마나 할지 명확히 한다.할 일에 머물고 필요할 때 의도적으로 쉰다.쓴 시간과 이번 행동이 만든 결과를 이해한다.반복 집중과 퀘스트 기여가 섬의 변화를 만든다.소통·탐색·꾸미기를 하거나 바로 다시 집중한다.
행동로그인 → 섬 만들기 또는 참여 → 입항할 일·목표 시간 설정 → 집중 시작집중 ↔ 잠시 휴식 · 선택적으로 이모티콘/공동 소리종료 → 기록·물고기·퀘스트 결과 확인퀘스트 참여 → 공동 자원 확인 → 시설 선택·건설편지/공지 · 통계/랭킹 · 다른 섬 · 개인/공동 꾸미기

시스템 응답인증과 소속을 확인하고 초기 시설을 보여 준다.세션을 만들고 허용 범위에서 Screen Time 실드를 적용한다.유효 집중과 휴식을 나누고 진행 세션을 복구한다.중복 없이 기록하고 각 결과와 재화 귀속을 구분한다.판정·보상을 확정하고 해금 조건과 잔액을 갱신한다.해금·역할·보유·공개 범위에 맞는 행동만 연다.
확정 규칙첫 건설은 집중 시작 조건이 아니다.권한 거부가 나머지 개인 설정을 잠그지 않는다.휴식은 종료가 아니며 유효 집중·보상에서 제외한다.목표 미달이어도 실제 집중 기록은 남긴다.회관→게시판은 고정, 이후 시설은 조건에 따라 선택한다.초대·알림·딥링크로 잠금이나 권한을 우회하지 않는다.

06의 모든 선택에는 집중 루프로 돌아가는 길이 있다.소통·탐색·꾸미기는 집중 완료 뒤 강제되는 코스가 아니다.
