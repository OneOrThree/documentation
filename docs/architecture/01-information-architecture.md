## 진입

스플래시에서 갈린다 — **신규는 온보딩**, **기존은 로그인·동기화** 후 곧장 홈.

## 온보딩 — 최초 1회 (O1~O8)

충격 → 측정 → 목표 → 계정 순서다. 남은 시간을 먼저 보여주고(O2) 실제 스크린타임을 붙여(O3·O4)
"이대로 살면" 예측(O5)까지 간 다음에야 목표를 받는다(O6). 로그인(O7)과 캐릭터 생성(O8)은 맨 뒤 —
**동기가 서기 전에 가입을 요구하지 않는다.**

| 단계 | 화면 |
|---|---|
| O1 | 성별·나이 |
| O2 | 남은 시간 충격 |
| O3 | 스크린타임 권한 (iOS) |
| O4 | 전날 스크린타임 |
| O5 | 인생 예측 |
| O6 | 목표 설정 (AI 추천) |
| O7 | 로그인 (Kakao / Apple) |
| O8 | 캐릭터 생성 · 닉네임 |

## 메인 — 하단 4탭 + 중앙 FAB

### 홈
방 + 캐릭터, 오늘 요약 카드(목표·현재·집중·진행도), 코인 잔액, 우편함.
방의 캐릭터를 탭하면 **상점으로 바로 넘어간다** — 꾸미기 동선이 홈에 붙어 있다.
우편함은 편지함 목록 → 편지 상세.

### 그룹 / 랭킹
두 축이다.
- **[그룹]** — 목록 → 상세(그룹원 기록 · 챌린지 현황 · 방장 설정/초대/나가기), 만들기(챌린지 지정), 검색·참가
- **[리그]** — 30명 주간 랭킹, 티어·순위·내 위치, 승격/강등 · 마감 카운트다운

### 집중 (중앙 FAB · F0~F3)
카테고리 선택(F0)에서 시작한다. 목록·누적을 보여주고 새 카테고리와 집중 아이템을 지정할 수 있다.
그다음 **개인 집중(F1) ↔ 그룹 집중·앰비언트(F2) 는 스와이프로 오간다** — 모드 전환이 별도 화면이 아니다.
그룹 집중에서는 **콕 찌르기**(그룹원 푸시)가 나간다.
어느 쪽이든 세션 결과(F3)로 수렴 — 집중시간·코인·Streak, 그리고 갓생 카드 공유.

### 상점
[치장] · [가구] · [집중 아이템] 3분류. 아이템 상세·미리보기 → 구매(코인/현금) 또는 장착.
보유함/장착 별도.

### 마이
목표 설정 변경 · 기록 보기([주][월][년]) · 권한 관리 · 계정 설정.

## 오버레이

**N1 AI 주간 편지** — 발행일에 1회성 알림으로 뜨고, **우편함에 영구 보관**된다.
탭 구조 바깥의 오버레이라서 어느 화면에서든 뜬다.
